# SockDrawer product

SockDrawer is a phone-local learning memory for people who want to save first and organize later. The primary user captures links, notes, and files on Android, retrieves relevant excerpts locally, and deliberately hands a grounded prompt to the ChatGPT mobile app.

Product principles:

- Capture must feel immediate, but success is shown only after durable phone storage.
- Organization is automatic and deterministic.
- Optional user labels take precedence over weak extracted titles and remain editable.
- The library and retrieval index stay on the phone.
- Public webpage extraction is stateless and protected.
- Sharing to ChatGPT is visible and user initiated.
- Backup is a first-class control because clearing Chrome data removes the library.
- The interface stays accessible, touch-friendly, youthful, and focused on Save, Review, Library, and Recall.
- The sock mascot communicates durable saves by moving into its drawer, with reduced-motion support.

MVP exclusions: OCR, cloud sync, multi-device access, direct file Share Target, and automatic MCP access.
